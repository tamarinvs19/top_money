## Implementation notes

### 1. Recent assets in the transaction form

- Added `RecentAsset` (`user`, `asset`, `used_at`) with `RECENT_ASSETS_LIMIT = 3`.
- `RecentAsset.record_usage()` upserts usage and deletes entries beyond the three newest.
- Usage is recorded after creating or editing a transaction for both selected assets.
- `RecentAsset.order_assets()` returns recent assets first (newest to oldest), followed by the remaining assets.
- Both `transaction_add` and `transaction_edit` pass the ordered asset list to the template, so Select2 shows recent assets at the top.
- Migration: `finance/migrations/0025_recentasset.py`.

### 2. Currency-aware statistics

- Added `CurrencyConverter.to_base()`. It converts to RUB using the transaction asset rate when a RUB asset is involved, otherwise falls back to the existing static `CurrencyConverter.RATES`.
- Asset rates store how many transaction-currency units equal one asset-currency unit, so the amount is divided by the rate.
- `transaction_amount_in_rub()` in `finance/views.py` selects the RUB-side asset rate when available.
- Statistics category amounts and totals, plus the monthly totals on the transactions page, now aggregate converted RUB amounts instead of raw mixed-currency values.

### 3. Bank and provider images in MEDIA

- Templates now use `{{ object.image.url }}` instead of `{% static object.image %}` for banks and providers.
- Bank and provider edit forms include a file input for replacing the logo.
- Registered `Bank` in Django admin with a logo preview and editable `image` field.
- Added data migration `finance/migrations/0026_migrate_bank_images_to_media.py`, which copies bundled `static/banks` and `static/providers` files into `MEDIA_ROOT`.
- `populate_banks` now copies bundled logos from static files into MEDIA, and `generate_logos` writes generated logos directly into MEDIA.
- Deployment note: ensure `MEDIA_ROOT` is writable and MEDIA files are served by the web server. Run `migrate` so existing bundled logos are copied.
- Cashback category icons still use static files; they are generated by the cashback category UI.

### 4. Transaction filters and statistics links

- Transactions page accepts `?type=<TYPE>&category=<CATEGORY>` and shows type/category dropdowns with a reset link.
- Invalid query values are ignored. Filters apply to the grouped list, day totals, and income/expense totals.
- Added year-scoped routes:
  - `transactions_year` → `/transactions/<year>/`
  - `transactions_year_asset` → `/transactions/<year>/<asset_uuid>/`
- Statistics category rows link to the matching filtered transactions page; month stats link to the month page and year stats link to the year page.
